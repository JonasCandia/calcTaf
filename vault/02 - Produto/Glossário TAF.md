# Glossário TAF

← [[00 - Início]] · relacionado: [[Regras de Negócio]], [[Funcionalidades Atuais (Web)]]

| Termo | Significado |
|---|---|
| **TAF** | Teste de Aptidão Física do CBMRS |
| **IR 001/2024** | Instrução Reguladora que define as regras e tabelas oficiais do TAF — ver [[Contexto Institucional]] |
| **Faixa etária** | Um dos 10 grupos de idade usados para selecionar o limiar de pontuação (até 19, 20-24, ..., 60+) |
| **Barra Fixa** | Teste de força superior para homens ≤ 39 anos — repetições |
| **Apoio sobre o solo** | Teste de força superior para homens > 39 anos — repetições |
| **Barra Isométrica** | Teste de força superior para mulheres ≤ 39 anos — tempo em segundos suspensa |
| **Apoio com joelhos** | Teste de força superior para mulheres > 39 anos — repetições |
| **Abdominal Remador** | Teste abdominal (1 minuto), mesmo teste para ambos os sexos, tabelas diferentes |
| **Corrida 12 min** | Distância total percorrida em 12 minutos (metros) — também chamada de teste de Cooper |
| **Natação 50m** | Teste opcional, tempo em segundos — quanto **menor** o tempo, melhor a pontuação (`lowerIsBetter`) |
| **Pontos** | Nota de 0 a 10 (em incrementos de 0,5 na maioria das tabelas) atribuída a cada teste conforme a marca obtida |
| **Nota final** | Média ponderada dos pontos dos testes, com peso 2 para a corrida |
| **Conceito** | Classificação textual da nota final: Excelente (≥10,0... na prática ≥ o próprio 10), Muito Bom (≥8,5), Bom (≥7,0), Regular (≥5,0), Insuficiente (<5,0) |
| **Aprovado/Reprovado** | Nota final ≥ 5,0 = aprovado; abaixo disso, reprovado |

Fonte de verdade destes termos e seus valores exatos: `src/lib/taf-utils.ts` e `src/constants/taf-data.ts`.
